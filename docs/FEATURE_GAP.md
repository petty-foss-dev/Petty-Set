# Feature gap: Lensflare → petty: set

Checked 2026-10-08 against [Lensflare's public feature and pricing page](https://lensflare.io/) and the current `main` implementation. This covers advertised behavior, not a hands-on audit of Lensflare's signed-in editor. “Partial” means a workflow exists but lacks important controls or outputs. The target is independent functionality using original code and assets.

## Current baseline

petty: set already has an editable 3D stage with drawn walls, rectangular room creation, shared-corner editing, wall splitting, intersection-aware interior partitions, endpoint and edge snapping, wall lengths, closed-room area and individual 3D floors, framed doorways and windows, adjoining room extension, blocks, tables, chairs, sofas, bookcases, plants, rugs, wooden drawing mannequins with visible joints, three pose presets, a reusable named pose library, per-shot joint controls and direct 3D joint handles, camera tripods and three light source styles; outdoor ground, sky and sun controls, plus original trees, benches, vehicles, styled ground patches, and backlot facades with editable signs, streetlamps and barrels; self-contained GLB imports up to 50 MB with portable project backups; numeric transforms and dimensions; top-plan and camera views; generic sensor gates and a small named camera and lens catalog, focal length, f-number, focus distance, field-of-view and approximate focus-range readouts, shot aspect framing guides, direct shot-to-shot camera switching and waypoint camera moves; floor-plan image overlay with editable scale, position, rotation and opacity plus two-point calibration; multiple scenes and shots; shot-specific actor marks and waypoint routes with a simple walk preview, plus a searchable procedural action library with per-shot loop and speed; separate story and shoot order; captured frames; notes and duration; undo/redo; local autosave; JSON import/export; shot-list CSV; measured floor-plan SVG; viewport PNG; and a basic storyboard PDF. The furnished sample includes two connected rooms, two camera setups, actor actions, and lights linked to a power source. The furnished, exterior, and backlot samples use original procedural geometry; their objects can all be edited independently.

## Build order

The named camera gates come from [ARRI's ALEXA 35 active image areas](https://www.arri.com/en/cine-systems/cine-cameras/legacy-cine-cameras/alexa-35), [Sony's FX3 sensor specifications](https://www.sony.com/electronics/support/camcorders-and-video-cameras-interchangeable-lens-camcorders/ilme-fx3/specifications), and [Blackmagic's Pocket Cinema Camera 6K Pro specifications](https://www.blackmagicdesign.com/products/blackmagicpocketcinemacamera/techspecs). The lens focal lengths, T ratings and close-focus distances come from [ZEISS CP.3 technical data](https://www.zeiss.com/photonics-and-optics/en/cinematography/lenses/compact-prime-cp-3-lenses.html). T-stop is transmission metadata and is kept separate from the f-number used for the approximate depth-of-field calculation; physical lens mount combinations still require a production check.

1. **Editor foundation (P0):** shaped room drawing, collinear overlap handling, multiple wall openings, batch selection, finishes and named layers are available; next add reliable per-shot scene state beyond actors and contextual tool and shot-navigation shortcuts.
2. **Film planning (P1):** visual focus and camera moves, fixture and beam planning, setup groups and production-quality exports.
3. **Motion and collaboration (P2):** rigged actor animation, editable power routing and Plan B, then optional hosted review and crew editing.

## Requests from filmmakers and open-source projects

Public filmmaker feedback on [ShotPad](https://www.reddit.com/r/Filmmakers/comments/1sgtkic/i_built_a_shot_planning_app_because_i_was_sick_of/) explicitly asks for bulk storyboard loading, reference images with shots, smooth floor-plan editing, Fountain script import, department note layers, and a useful demo project. A separate [ShotPrep discussion](https://www.reddit.com/r/Filmmakers/comments/1spplhm/i_spent_the_past_year_combining_shot_lists/) emphasizes linked shot lists, storyboards, lighting, schedules, and call sheets. [Open Shot Designer](https://github.com/koosoli/OpenShotDesigner) shows a broad open-source planning workflow with floor plan, script, equipment, rigging, power, and continuity tools. These are research inputs, not claims about Lensflare itself.

Prioritize the following additions after the current storyboard import:

1. **Connected planning data:** setup-level editing and shot status now share one shot model across boards, list and exports; next derive shoot-day sheets from the same data.
2. **Fast spatial editing:** multi-select, reliable rotation handles, department annotation layers, and tablet pen input.
3. **Production interchange:** Fountain scene import, batch reference management, richer PDF/CSV export, and a portable local project archive.
4. **On-set use:** optional continuity notes and take logging linked to a shot. Keep script input optional for unscripted work.

Reference images are resized for editing, stored separately in IndexedDB, and embedded in portable project exports. Large image libraries still need performance and storage-pressure testing.

The light trace is a **direct illumination estimate** on the floor in lux. Click the plan floor to meter any point and see each visible fixture's contribution. It uses fixture lumens, beam geometry, inverse-square falloff, floor incidence, wall/opening visibility, and rotated-box proxies for solid props. Three.js renders the matching fixtures with candela-based spot/point lights and shadow maps. It does not yet solve indirect bounce, glass transmission, IES distribution, detailed mesh transmission/occlusion, or calibrated exposure. Three.js [SpotLight](https://threejs.org/docs/pages/SpotLight.html) and [PointLight](https://threejs.org/docs/pages/PointLight.html) document their candela units and inverse-square decay; [RectAreaLight](https://threejs.org/docs/pages/RectAreaLight.html) cannot cast shadows in this WebGL renderer, so the softbox remains a shadow-casting approximation.

## Scope note

Lensflare advertises **set building to scale** with walls, shapes and room pieces. It does not publicly claim Blender-style arbitrary mesh sculpting. If petty: set should include freeform mesh editing or import of GLB/OBJ assets, treat that as an additional product feature beyond the published parity target.
