# Feature gap: Lensflare → petty: set

Checked 2026-10-08 against [Lensflare's public feature and pricing page](https://lensflare.io/) and the current `main` implementation. This covers advertised behavior, not a hands-on audit of Lensflare's signed-in editor. “Partial” means a workflow exists but lacks important controls or outputs. The target is independent functionality using original code and assets.

## Current baseline

petty: set already has an editable 3D stage with drawn walls, endpoint snapping, framed doorways and windows, adjoining room extension, blocks, tables, chairs, sofas, bookcases, plants, rugs, wooden drawing mannequins with visible joints, camera tripods and three light source styles; small GLB imports; numeric transforms and dimensions; top-plan and camera views; three sensor gate presets, lens presets, focal length, aperture, focus distance, field-of-view and approximate focus-range readouts, shot aspect framing guides and waypoint camera moves; floor-plan image overlay with editable scale, position, rotation and opacity; multiple scenes and shots; shot-specific actor marks; separate story and shoot order; captured frames; notes and duration; undo/redo; local autosave; JSON import/export; shot-list CSV; viewport PNG; and a basic storyboard PDF. The furnished scene is original procedural geometry; its objects can all be edited independently.

## Build order

1. **Editor foundation (P0):** persistent shared wall corners and room editing, multi-select and reliable per-shot scene state beyond actors.
2. **Film planning (P1):** named camera/lens catalog and visual focus, fixture and beam planning, setup groups, shot-list PDF and production-quality exports.
3. **Motion and collaboration (P2):** actor/camera animation, power routing and Plan B, then optional hosted review and crew editing.

## Scope note

Lensflare advertises **set building to scale** with walls, shapes and room pieces. It does not publicly claim Blender-style arbitrary mesh sculpting. If petty: set should include freeform mesh editing or import of GLB/OBJ assets, treat that as an additional product feature beyond the published parity target.
